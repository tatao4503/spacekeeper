# 다른 Mac에서 한 번 돌려보기

Spacekeeper는 지금까지 **만든 사람의 Mac 한 대에서만** 실행됐습니다.
그래서 "내 환경에서는 됨" 이상을 말할 수 없습니다. 이 문서는 그 공백을 메우기 위한
30분짜리 점검표입니다. 개발 지식이 없어도 따라 할 수 있게 썼습니다.

문제가 하나도 없어도 그 사실 자체가 결과입니다. 알려주세요.

---

## 0. 시작 전

- **Apple Silicon Mac** (M1 이후)에서만 동작합니다. Intel Mac은 지원하지 않습니다.
  - 확인: 왼쪽 위 사과 → `이 Mac에 관하여` → 칩이 `Apple M...` 이면 OK
- **macOS 12 (Monterey) 이상**이어야 합니다.
- 이 앱은 **아무것도 삭제하지 않습니다.** 정리는 파일을 `~/.spacekeeper/quarantine/`로
  옮기는 것이고, 언제든 되돌릴 수 있습니다. 그래도 불안하면 **아무것도 정리하지 말고
  화면만 봐 주셔도 됩니다.** 그것만으로도 대부분의 확인이 됩니다.

## 1. 설치

1. https://github.com/tatao4503/spacekeeper/releases/latest 에서
   `Spacekeeper_0.2.0_aarch64.dmg` 다운로드
2. DMG를 열고 `Spacekeeper`를 `Applications`로 드래그
3. **처음 열 때는 반드시** — 응용 프로그램 폴더에서 아이콘을 **우클릭 → 열기** →
   경고창에서 다시 **열기**
   - 그냥 더블클릭하면 "확인되지 않은 개발자"라며 열리지 않습니다. 이건 정상입니다
     (공증을 받지 않은 앱이라 그렇습니다). 한 번만 이렇게 열면 이후엔 그냥 열립니다.

> ⚠️ **여기서 막히면 그것이 가장 중요한 결과입니다.** 어떤 문구가 떴는지 캡처해서 알려주세요.

## 2. 확인해 주실 것 (각 1~2분)

체크만 해 주시면 됩니다. `□` 에 O/X 를 적어 주세요.

| | 확인할 것 | 어떻게 |
|---|---|---|
| □ | 앱이 열린다 | 창이 뜨고 왼쪽에 메뉴 목록이 보이는가 |
| □ | 첫 화면 설명이 보인다 | 처음 실행하면 안전 원칙 설명이 먼저 뜨는가 |
| □ | 글자가 깨지지 않는다 | 한글이 □□□ 로 보이거나 글자가 잘리지 않는가 |
| □ | 밝은 화면/어두운 화면 | 시스템 설정에서 라이트/다크를 바꿨을 때 앱도 따라 바뀌는가 |
| □ | 분석이 끝난다 | `공간 요약`에서 **다운로드** 폴더를 골라 분석 → 끝나는가 (멈추지 않는가) |
| □ | 결과에 이유가 붙어 있다 | 나온 항목마다 "왜 후보인지" 설명이 있는가 |
| □ | 디스크 지도 | `디스크 지도` 탭에서 블록들이 보이고 눌러서 들어가지는가 |
| □ | **시스템 데이터** | `시스템 데이터` → `분석` (30초~2분) → 항목들이 나오는가 |
| □ | 영어 전환 | 왼쪽 아래 `English` → 화면이 전부 영어로 바뀌는가 (한글이 남아 있으면 알려주세요) |
| □ | 환경 진단 | `환경 진단` 탭 → 항목들이 통과로 뜨는가 |

## 3. 여유가 되면 (안 하셔도 됩니다)

- `공간 요약`에서 **확실히 필요 없는 것 하나만** 골라 `선택 항목 격리`
- `격리함` 탭에서 그 항목을 **복원** → 원래 자리로 정확히 돌아왔는지 Finder에서 확인
- 이게 이 앱의 핵심 약속이라, 다른 Mac에서도 지켜지는지가 가장 궁금합니다.

## 4. 알려주실 것

문제가 있었다면:

- **어느 단계에서** (위 표의 항목 번호)
- **화면 캡처** (⌘⇧4 로 영역 선택)
- **Mac 정보**: 사과 → `이 Mac에 관하여` 의 칩·macOS 버전

문제가 없었다면 그냥 "다 됐다"고만 알려주셔도 충분합니다.
그게 이 앱에 대해 지금 없는 유일한 정보입니다.

## 5. 지우고 싶으실 때

1. `Spacekeeper.app`을 휴지통으로
2. 홈 폴더의 `.spacekeeper` 폴더 삭제 (Finder에서 `⌘⇧.` 로 숨김 파일 표시)
   - 격리한 게 있다면 **먼저 복원한 뒤** 지워 주세요.

앱은 계정을 만들지 않고, 인터넷으로 아무것도 보내지 않습니다. 지우면 흔적이 남지 않습니다.
